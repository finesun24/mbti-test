프로젝트 내 모든 `.html` 파일을 대상으로 다음 항목을 점검하라.

## 점검 항목

1. **제목(title)**: 각 HTML 파일에 `<title>` 태그가 있는지, 비어있지 않은지 확인
2. **깨진 링크**: `<a href>`, `<link href>`, `<script src>`, `<img src>` 등이 가리키는
   내부 파일 경로가 실제로 존재하는지 확인 (외부 URL은 형식만 점검, 실제 요청은 보내지 않음)
3. **콘솔 에러**: 가능하면 claude-in-chrome 스킬로 각 페이지를 열어 콘솔 에러/경고를 확인.
   브라우저 확인이 불가능한 상황이면 정적 분석으로 대체하고 그 사실을 명시할 것
   (예: 존재하지 않는 스크립트 참조, 문법 오류가 뚜렷한 인라인 스크립트 등)

## 절차

1. 프로젝트 루트에서 모든 `*.html` 파일을 찾는다.
2. 파일별로 위 세 항목을 각각 점검한다.
3. 결과를 아래 형식의 표로 정리해서 보고한다.

## 보고 형식

| 파일 | 제목 | 깨진 링크 | 콘솔 에러 | 상태 |
|---|---|---|---|---|
| index.html | OK / 제목 없음 | 없음 / `./foo.css` 없음 | 없음 / 에러 내용 | 통과 / 수정 필요 |

- "상태" 열은 세 항목 중 하나라도 문제가 있으면 "수정 필요", 모두 이상 없으면 "통과"로 표기한다.
- 표 아래에 "수정 필요" 파일들에 대해 구체적으로 무엇을 고쳐야 하는지 항목별로 정리한다.
- 코드를 임의로 수정하지 말고, 점검과 보고만 수행한다.
